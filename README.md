# Try Risk-Free Case Study

A web-based case study by Jessica Le on TikTok Shop Beauty’s Try Risk-Free program. It examines expansion opportunities, operational bottlenecks, and possible next steps.

Built as a self-contained HTML presentation with keyboard navigation.

## Live site

https://jessica-leee.github.io/try-risk-free-case-study/

## View locally

Open `index.html` in a browser, or serve the repository:

```sh
python3 -m http.server 8000
```

Then open [localhost:8000](http://localhost:8000). The presentation is
self-contained; there are no packages to install or services to configure.

## Navigation

| Action | Control |
| --- | --- |
| Next slide | Right arrow, Space, or Page Down |
| Previous slide | Left arrow or Page Up |
| First / last slide | Home / End |
| Toggle fullscreen | F |

Clicking the right or left side of the screen also advances or goes back.

## Files and editing

- `index.html` is the published entry point. Slide content, styles, and the
  navigation script are in this file.
- `JessicaLe_TryRiskFree_CaseStudy.html` is the original named copy. It matches
  the entry point at the time of this documentation update.

Edit `index.html` for changes to the published presentation. If retaining the
named copy, update it deliberately to avoid two competing versions.

This is a qualitative product case study. The proposed next steps are ideas
for evaluation; the repository does not report measured business outcomes.
